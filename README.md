# درع الاحتيال — Fraud Shield 🛡️

افحص أي رابط **قبل فتحه** واحمِ نفسك من الاحتيال المالي: كشف مواقع البنوك والجهات المقلدة، والروابط المختصرة، وصفحات رمز التحقق (OTP) الوهمية — مع حكم عربي واضح: 🟢 آمن / 🟡 مشبوه / 🔴 خطر.

**نقطتا الاستخدام كما هي بالضبط:**

1. 📱 **موقع إلكتروني (Vercel) + تطبيق اختصارات Apple**: تدخل الموقع **مرة واحدة فقط**، تنسخ رابطاً وتضيف اختصاراً بسيطاً — بعدها تفحص أي رابط من زر المشاركة داخل أي تطبيق دون العودة للموقع.
2. 🧩 **إضافة Google Chrome**: حماية داخل المتصفح — وسم نتائج البحث بشارات ملونة، حجب الروابط الخطر قبل فتحها، واعتراض نماذج البطاقة وOTP.

> بلا مكتبات خارجية، بلا build step، بلا قواعد بيانات — كل الملفات جاهزة للنشر فوراً.

## 1) النشر على Vercel (دقيقتان)

### الطريقة الأسهل — من الموقع
1. ارفع المستودع إلى GitHub (الأوامر أدناه).
2. افتح [vercel.com/new](https://vercel.com/new) واختر المستودع `fraud-shield`.
3. اضغط **Deploy** — لا إعدادات مطلوبة: Vercel يكتشف `public/` تلقائياً كواجهة و`api/` كدوال خادمية.
4. ستحصل على رابط مثل `https://fraud-shield-xxx.vercel.app` — هذا هو موقعك.

### الطريقة البديلة — من الطرفية
```bash
npm i -g vercel
cd fraud-shield
vercel --prod
```

### اختياري: ربط طبقة الذكاء الاصطناعي (المرحلة 3)
من إعدادات المشروع في Vercel ← Environment Variables:
- `PCS_AI_ENDPOINT` = رابط أي نموذج تصنيف يستقبل `{url, source, verdict}` ويرد `{adjust: رقم, reason: نص}`
- `PCS_AI_KEY` = مفتاح المصادقة

بدون هذه المتغيرات يعمل الفحص القاعدي بالقواعد المحلية كاملاً.

## 3) إضافة الفحص إلى تطبيق «الاختصارات» (آيفون/آيباد)

افتح موقعك المنشور — قسم **«التثبيت في تطبيق الاختصارات — لمرة واحدة فقط»** يحتوي على:
- **أزرار نسخ جاهزة** تعبئ رابط موقعك تلقائياً.
- **الوصفة الأسرع** (6 خطوات): اختصار يفحص الرابط عبر `‎/api/scan` ويعرض تنبيهاً فورياً بصيغة جاهزة (الحكم + الدرجة + الأسباب) دون فتح أي صفحة.
- **الوصفة البديلة**: فتح صفحة النتيجة الملونة عبر `‎/?url=...`.

الخلاصة التقنية: الاختصار يستقبل الرابط من Share Sheet ← ترميز URL ← استدعاء `https://موقعك/api/scan?url=<الرابط>&source=shortcut` ← قراءة حقل `display` من الرد ← إظهار تنبيه.

## 4) تثبيت إضافة Chrome

1. نزّل المستودع (Code ← Download ZIP) وفك الضغط.
2. `chrome://extensions` ← **Developer mode** ← **Load unpacked** ← مجلد `extension`.
3. اختياري: من إعدادات الإضافة فعّل **الخادم السحابي** والصق رابط موقعك على Vercel — يدمج نتائج الخادم مع الفحص المحلي الفوري (الدرجة الأسوأ تحسم، وفشل الخادم لا يعطل الحماية).

> للنشر في متجر Chrome Web Store: اضغط مجلد `extension` في ZIP وارفعه في [لوحة المطورين](https://chrome.google.com/webstore/devconsole) (رسوم تسجيل لمرة واحدة).

## API

| Endpoint | الوظيفة |
|---|---|
| `GET /api/scan?url=...&source=search\|maps\|message\|direct\|shortcut` | فحص رابط → `{ok, verdict: {score, level, levelText, reasons[]}, display}` — `display` نص عربي جاهز للعرض في التنبيهات |
| `POST /api/scan` | نفس الفحص عبر JSON `{url, source}` |
| `POST /api/report` | بلاغ `{url, note?, level?, source?}` |
| `GET /api/threats` | تجميع الحملات حسب النطاق والمصدر + السجل + البلاغات |
| `GET /api/health` | جاهزية + عدّادات + حالة طبقة AI |

- **CORS مفتوح** و`Access-Control-Allow-Origin: *` على كل الـ endpoints (تستخدمها الإضافة واختصارات iOS).
- **حد معدل**: 120 طلب/دقيقة لكل IP لكل نسخة دالة.
- **ملاحظة صريحة**: سجل الفحوصات والبلاغات في ذاكرة كل نسخة دالة (ephemeral) — يُعاد بناؤه بعد إعادة النشر؛ للسجل الدائم اربط قاعدة بيانات لاحقاً.

## الاختبارات (كلها خضراء)

- **45 اختبار محرك**: `node scripts/test_engine.js` — انتحال الجهات، Typosquatting، Homoglyphs، المختصرات، IP، `@`، مصدر السياق، نص العرض، وحالات آمنة لمنع الإيجابيات الكاذبة.
- **26 اختبار الخادم المحلي**: `node scripts/test_server.js` (نسخة الهاكاثون في مجلد `proactive-context-shield`).
- **17 اختبار دوال Vercel**: `node scripts/test_api.js` — المحولات الخادمية بطلبات وهمية + CORS + حد المعدل.
- **فحص المستودع**: `python3 scripts/validate_repo.py` — manifest، صيغة كل JS، JSON، الأيقونات، اكتمال الملفات.

> السكربتات في مجلد `scripts/` بمستودع العمل؛ يمكنك نقلها للمستودع إن أردت تضمين الاختبارات مع الكود.

## الخصوصية والحدود

- الإضافة افتراضياً: **صفر طلبات شبكة** — كل الفحص محلي في الجهاز؛ وضع السحابة اختياري بخدمتك.
- الخادم يفحص الرابط ويحفظ (النطاق + الدرجة + المصدر) في الذاكرة لدعم البلاغات — لا بيانات شخصية ولا محتوى صفحات.
- الفحص القاعدي قواعد محلية (لا WHOIS ولا قوائم حية إلا بربط طبقة AI) — والنتائج مؤشر لا حكم نهائي: لا تزال تعامل الروابط الحساسة بحذر.
