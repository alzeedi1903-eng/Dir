# حصن (Hisn) — جدار فحص الروابط 🏰

جدار فحص تلقائي يقع **بين نقرة المستخدم وفتح الموقع**: أي رابط يُفحص قبل اكتمال تحميله — حتى لو فُتح من تطبيق خارجي أو رسالة أو إعادة توجيه — مع **مقارنة فورية** بين الرابط المشبوه وموقعه الرسمي حرفاً بحرف، وحكم عربي واضح: 🟢 آمن / 🟡 مشبوه / 🔴 خطر.

**القدرات الثلاث الأساسية:**

1. 🧱 **الجدار التلقائي**: إضافة Chrome تفحص كل تنقل قبل تحميله (حتى نقرات الروابط القادمة من تطبيقات خارجية)، وكل نطاق خطر يُكتشف يدخل «الجدار الصلب» — قاعدة حجب على مستوى الشبكة تمنع أي وصول لاحق فوراً، من أي مصدر.
2. ⚖️ **المقارنة الفورية**: عند اكتشاف انتحال يُعرض الرابط المشبوه مقابل الموقع الرسمي للجهة — الجزء المزيَّف مضاءً بالأحمر والرسمي بالأخضر، مع عدد الحروف المختلفة والحروف المتشابهة المُستبدلة وزر مباشر للموقع الرسمي — كل ذلك بلا أي طلب شبكة (زمن الفحص يظهر بالمللي ثانية).
3. 📱 **الفحص من الهاتف**: موقع Vercel + اختصارات Apple بتثبيت بنقرة واحدة — ملفا `.shortcut` جاهزان وروابط استيراد مباشرة تنقلك من الموقع إلى تطبيق الاختصارات فوراً (الحافظة + ورقة المشاركة)، مع وصفات يدوية كبديل احتياطي. تفحص أي رابط من أي تطبيق وتعرض النتيجة فوراً.

> بلا مكتبات خارجية، بلا build step، بلا قواعد بيانات — كل الملفات جاهزة للنشر فوراً.

## كيف يعمل الجدار التلقائي؟

| الطبقة | متى تعمل | ماذا تفعل |
|---|---|---|
| **الفحص الفوري** | عند بدء أي تنقل (قبل اكتمال التحميل) | محرك محلي فوري: انتحال الجهات، Typosquatting، Homoglyphs، المختصرات، الكلمات الخطرة — النطاق الخطر يُستبدل بصفحة اعتراض قبل أن يُحمَّل أي بايت |
| **الجدار الصلب (DNR)** | بعد أول كشف لنطاق خطر | يُضاف النطاق إلى قواعد `declarativeNetRequest` — أي محاولة وصول لاحقة (رابط، إعادة توجيه، إطار، تطبيق خارجي) تُحجب على مستوى الشبكة قبل أي كود |
| **تنقلات SPA** | عند تغيير الصفحة لعنوانها داخلياً (pushState) | تُفحص كأي تنقل آخر |
| **التجاوز الواعي** | زر «متابعة على مسؤوليتي» | يزيل قاعدة الجدار الصلب للنطاق لمدة 10 دقائق ثم يعيد بناءها تلقائياً عند أول خطر جديد |

الروابط القادمة من **تطبيقات خارجية** (واتساب، البريد، الرسائل) تفتح في المتصفح — فيصلكم الجدار على كل نقرة مهما كان مصدرها.

## 1) النشر على Vercel (دقيقتان)

### الطريقة الأسهل — من الموقع
1. ارفع المستودع إلى GitHub (الأوامر أدناه).
2. افتح [vercel.com/new](https://vercel.com/new) واختر المستودع `hisn`.
3. اضغط **Deploy** — لا إعدادات مطلوبة: Vercel يكتشف `public/` تلقائياً كواجهة و`api/` كدوال خادمية.
4. ستحصل على رابط مثل `https://hisn-xxx.vercel.app` — هذا هو موقعك.

### الطريقة البديلة — من الطرفية
```bash
npm i -g vercel
cd hisn
vercel --prod
```

### طبقة الذكاء الاصطناعي — Gemini (اختيارية، بلا مفتاح يعمل كل شيء محلياً)

الخادم يدمج **Gemini فوق المحرك المحلي الفوري**: القواعد المحلية تحسم خلال أجزاء من الثانية، ثم يراجع Gemini النتيجة بمعرفته بالنطاقات الرسمية للبنوك والجهات الخليجية ويصححها إن لزم — **والأسوأ بين النتيجتين هو الحكم النهائي** (الذكاء الاصطناعي لا يخفض أبداً كشف القواعد المحلية، فقط يرفعه). أي فشل في Gemini (لا مفتاح / مهلة 9 ثوانٍ / خطأ شبكة) يعيد الاستجابة بنتيجة المحرك المحلي كما هي — **الخدمة لا تفشل أبداً بسبب طبقة الذكاء**.

**التشخيص عبر حقل `ai` في استجابة `/api/scan`:** `attempted: true` يعني أن المفتاح مضبوط في الخادم؛ وإن ظهر مع `used: false` فالسبب مبيَّن في `error` برمز آمن: `http_400/403` = المفتاح غير صالح أو Generative Language API غير مفعّل للمشروع (الأشهر: نسخ المفتاح مع اقتباسات `"..."` أو فراغات زائدة، أو مفتاح حُذف من AI Studio) · `http_429` = نفدت الحصة المجانية للنموذج · `timeout` = تجاوز 9 ثوانٍ · `network` = تعذر الوصول للخدمة · `bad_json` = رد غير مفهوم · `http_404` = المفتاح مقبول لكن الرابط أو اسم النموذج خاطئ — احذف من Vercel المتغيرين الاختياريين `PCS_GEMINI_ENDPOINT` و`PCS_GEMINI_MODEL` إن وُجدا (وجودهما يظهر بلا أي قيم في `/api/health` عبر `aiEndpointCustom` و`aiModelOverride`) ثم Redeploy. في كل الحالات يعمل الفحص المحلي فوراً بلا أي انقطاع.

التفعيل (مرة واحدة):
1. أنشئ مفتاح API من [Google AI Studio](https://aistudio.google.com/apikey).
2. لوحة تحكم Vercel ← المشروع ← Settings ← **Environment Variables** ← أضف `GEMINI_API_KEY` بقيمة المفتاح ← Save.
3. Deployments ← **Redeploy** على آخر نسخة.

متغيرات إضافية اختيارية:
- `PCS_GEMINI_MODEL` = تجاوز يدوي لاسم النموذج (بدونه تُستخدم سلسلة تلقائية: `gemini-3.5-flash-lite` ← `gemini-flash-latest` ← `gemini-3.8-flash` ← `gemini-2.5-flash` — عند 404 لنموذج تقاعد تُجرَّب البدائل بالترتيب ويثبت الناجح)
- `PCS_GEMINI_ENDPOINT` = تجاوز رابط الخدمة (للاختبار أو وسيط خاص)
- `PCS_AI_ENDPOINT` / `PCS_AI_KEY` = طبقة ذكاء عامة بديلة (تُستخدم فقط إن لم يوجد مفتاح Gemini)

**ملاحظة خصوصية صريحة:** عند تفعيل المفتاح، يُرسل (الرابط + مصدره + ملخص نتيجة المحرك المحلي) إلى Google لتحليله — بلا مفتاح، لا يخرج أي شيء من الخادم أبداً.

## 3) الفحص التلقائي من الهاتف (آيفون/آيباد)

افتح موقعك المنشور — قسم **«الفحص التلقائي من الهاتف»** فيه أزرار نسخ تعبئ رابط موقعك تلقائياً + أربع وصفات:

| الوصفة | مدى الأتمتة | يعمل في |
|---|---|---|
| **فحص الحافظة + اللمس الخلفي** (الموصى بها) | انسخ الرابط ← اضغط مرتين على خلف الهاتف ← إشعار فوري بالحكم | أي تطبيق |
| **ورقة المشاركة (Share Sheet)** | زر المشاركة ← «فحص الرابط» ← تنبيه فوري | أي تطبيق |
| **زر المفضلة الذكي** | نقرة واحدة أثناء التصفح تفحص الصفحة الحالية | Safari |
| **إضافة Safari Web Extension** | تلقائي كامل: شارات على الروابط وحجب الخطر دون أي نقرة | Safari — البناء يتطلب Mac + Xcode (دليل `safari-ios/`) |

الخلاصة التقنية: كل الوصفات تستدعي `https://موقعك/api/scan?url=<الرابط>&source=shortcut|clipboard|bookmark&format=text` فترجع النتيجة نصاً عربياً جاهزاً (الحكم + الدرجة + الأسباب) يُعرض مباشرة بإشعار أو تنبيه أو Show Result — بلا أي تحليل JSON.

> **شفافية تقنية:** Apple لا تسمح لأي طرف ثالث باعتراض كل نقرات الروابط في جميع التطبيقات — هذه أقرب نقاط الأتمتة الممكنة على iOS، والفحص يصبح تلقائياً بالكامل داخل Safari عبر الإضافة.

## 4) تثبيت إضافة Chrome

1. نزّل المستودع (Code ← Download ZIP) وفك الضغط.
2. `chrome://extensions` ← **Developer mode** ← **Load unpacked** ← مجلد `extension`.
3. اختياري: من إعدادات الإضافة فعّل **الخادم السحابي** والصق رابط موقعك على Vercel — يدمج نتائج الخادم مع الفحص المحلي الفوري (الدرجة الأسوأ تحسم، وفشل الخادم لا يعطل الحماية).
4. من الإعدادات أيضاً: **الجدار الصلب** (مفعّل افتراضياً) — الحجب الفوري على مستوى الشبكة للنطاقات الخطرة.

> للنشر في متجر Chrome Web Store: اضغط مجلد `extension` في ZIP وارفعه في [لوحة المطورين](https://chrome.google.com/webstore/devconsole) (رسوم تسجيل لمرة واحدة).

## API

| Endpoint | الوظيفة |
|---|---|
| `GET /api/scan?url=...&source=search\|maps\|message\|direct\|shortcut\|clipboard\|bookmark` | فحص رابط → `{ok, verdict: {score, level, levelText, reasons[], comparison?, aiProvider?}, display, classification, safety_score, official_domain, ai: {used, provider, attempted, error}, timing}` — `verdict.score` درجة خطر (100 = أشد) بينما `safety_score` درجة أمان معكوسة (100 = آمن تماماً)، و`classification` الحكم العربي كسلسلة، و`official_domain` النطاق الرسمي عند انتحال (من المقارنة المحلية الموثقة أو تحليل Gemini)، و`comparison` بيانات المقارنة الحرفية، و`timing.ms` زمن الفحص؛ وأضف `&format=text` لتعود النتيجة نصاً عربياً جاهزاً للعرض (`text/plain`) — هو ما تستخدمه ملفات التثبيت بنقرة واحدة على iOS |
| `POST /api/scan` | نفس الفحص عبر JSON `{url, source}` |
| `POST /api/report` | بلاغ `{url, note?, level?, source?}` (الحقول مقصوصة: url ≤ 2000، note ≤ 500) |
| `GET /api/threats` | تجميع الحملات حسب النطاق والمصدر + سجل مبهم (النطاق فقط دون العناوين الكاملة) + البلاغات |
| `GET /api/health` | جاهزية + عدّادات + حالة طبقة AI |

- **CORS مفتوح** و`Access-Control-Allow-Origin: *` على كل الـ endpoints (تستخدمها الإضافة واختصارات iOS).
- **حد معدل**: 120 طلب/دقيقة لكل IP لكل نسخة دالة.
- **ملاحظة صريحة**: سجل الفحوصات والبلاغات في ذاكرة كل نسخة دالة (ephemeral) — يُعاد بناؤه بعد إعادة النشر؛ للسجل الدائم اربط قاعدة بيانات لاحقاً.

## الاختبارات (كلها خضراء)

- **67 اختبار محرك**: `node scripts/test_engine.js` — انتحال الجهات، Typosquatting، Homoglyphs، المختصرات، IP، `@`، مصدر السياق، نص العرض، والمقارنة الفورية (14 اختباراً)، الخطأ المركب (تشابه اسم الجهة داخل تركيبة نطاق مزيّفة مثل حذف حرف + لاحقة ثقة، وعقوبة `COMPOUND`)، وحالات آمنة لمنع الإيجابيات الكاذبة.
- **26 اختبار الخادم المحلي**: `node scripts/test_server.js` (نسخة الهاكاثون في مجلد `proactive-context-shield`).
- **37 اختبار دوال Vercel**: `node scripts/test_api.js` — المحولات الخادمية بطلبات وهمية + CORS + حد المعدل + خصوصية threats + طبقة Gemini (بلا مفتاح = سلوك مطابق، فشل الخدمة = احتياطي سلس برمز تشخيص آمن، خادم وهمي = دمج متحفظ صحيح).
- **فحص المستودع**: `python3 scripts/validate_repo.py` — manifest، صيغة كل JS، JSON، الأيقونات، اكتمال الملفات.

> السكربتات في مجلد `scripts/` بمستودع العمل؛ يمكنك نقلها للمستودع إن أردت تضمين الاختبارات مع الكود.

## الخصوصية والحدود

- الإضافة افتراضياً: **صفر طلبات شبكة** — كل الفحص محلي في الجهاز؛ وضع السحابة اختياري بخدمتك.
- الخادم يفحص الرابط ويحفظ (النطاق + الدرجة + المصدر) في الذاكرة لدعم البلاغات — لا بيانات شخصية ولا محتوى صفحات، و`/api/threats` لا يعرض عناوين URL كاملة ولا ملاحظات المبلّغين.
- الفحص القاعدي قواعد محلية فورية، وطبقة Gemini اختيارية تراجع وتعزز (انظر قسمها أعلاه وملاحظة الخصوصية فيه) — والنتائج مؤشر لا حكم نهائي: لا تزال تعامل الروابط الحساسة بحذر.
