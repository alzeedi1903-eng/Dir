# حصن — Hisn Link Shield 🛡️
افحص أي رابط **قبل فتحه** واحمِ نفسك من الاحتيال المالي: كشف مواقع البنوك والجهات المقلدة، والروابط المختصرة، وصفحات رمز التحقق (OTP) الوهمية — مع حكم عربي واضح: 🟢 آمن / 🟡 مشبوه / 🔴 خطر، ومقارنة فورية بين الرابط المشبوه والموقع الرسمي.
**نقطتا الاستخدام كما هما بالضبط:**
1. 📱 **موقع إلكتروني (Vercel) + تطبيق اختصارات Apple**: التثبيت بنقرة واحدة من الموقع — الدالة `/api/shortcut` تولّد ملف الاختصار بعنوان موقعك محفوراً داخله، وبعدها تفحص أي رابط من زر المشاركة أو الحافظة دون العودة للموقع.
2. 🧩 **إضافة Google Chrome**: حماية داخل المتصفح — فحص كل تنقل قبل تحميله، جدار صلب على مستوى الشبكة (declarativeNetRequest)، وسم نتائج البحث بشارات ملونة، واعتراض نماذج البطاقة وOTP، ومقارنة فورية في النافذة المنبثقة وصفحة الحجب.
> بلا مكتبات خارجية، بلا build step، بلا قواعد بيانات — كل الملفات جاهزة للنشر فوراً.

## 1) النشر على Vercel (دقيقتان)
### الطريقة الأسهل — من الموقع
1. ارفع المستودع إلى GitHub (الأوامر أدناه).
2. افتح [vercel.com/new](https://vercel.com/new) واختر المستودع.
3. اضغط **Deploy** — لا إعدادات مطلوبة: Vercel يكتشف `public/` تلقائياً كواجهة و`api/` كدوال خادمية.
4. ستحصل على رابط مثل `https://hisn-xxx.vercel.app` — هذا هو موقعك.
### الطريقة البديلة — من الطرفية
```bash
npm i -g vercel
cd hisn
vercel --prod
```
### اختياري: طبقة التحليل الذكي (Gemini)
من إعدادات المشروع في Vercel ← Environment Variables:
- `GEMINI_API_KEY` = مفتاح Google AI Studio — يفعّل تحليل Gemini فوق المحرك المحلي (الأسوأ بين النتيجتين يحسم).
- `PCS_GEMINI_MODEL` = تجاوز اسم النموذج (اختياري — الافتراضي سلسلة نماذج تتبادل تلقائياً عند 404).
- `PCS_GEMINI_ENDPOINT` = نقطة نهاية مخصصة (اختياري — للاختبار أو وسيط خاص).
- `PCS_AI_ENDPOINT` / `PCS_AI_KEY` = طبقة AI عامة بديلة تُستخدم فقط إن لم يوجد مفتاح Gemini، تستقبل `{url, source, verdict}` وترد `{adjust: رقم, reason: نص}`.
بدون هذه المتغيرات يعمل الفحص القاعدي بالقواعد المحلية كاملاً.

## 3) إضافة الفحص إلى تطبيق «الاختصارات» (آيفون/آيباد)
افتح موقعك المنشور — قسم **«الفحص التلقائي من الهاتف — تثبيت بنقرة واحدة»** يحتوي على:
- **زرّا تثبيت جاهزان** (الحافظة + المشاركة): ينتقلان إلى تطبيق «الاختصارات» مباشرة — الملف تولّده `/api/shortcut` لحظة الطلب بعنوان موقعك محفوراً داخله، فلا لصق يدوي إطلاقاً.
- **ملاحظة صريحة**: iOS يطلب تفعيل **«السماح بالاختصارات غير الموثوقة»** لاستيراد ملفات غير موقعة (الإعدادات ← الاختصارات) — الموقع يشرح الخطوة عند أول استخدام.
- **الوصفات اليدوية البديلة** تبقى في القسم القابل للفتح: فحص عبر `‎/api/scan` بنص جاهز للعرض، أو صفحة النتيجة الملونة عبر `‎/?url=...`.
الخلاصة التقنية: الاختصار يستقبل الرابط من الحافظة أو Share Sheet ← ترميز URL ← استدعاء `https://موقعك/api/scan?url=<الرابط>&format=text` ← إظهار النتيجة النصية العربية فوراً.
## 4) تثبيت إضافة Chrome
1. نزّل المستودع (Code ← Download ZIP) وفك الضغط.
2. `chrome://extensions` ← **Developer mode** ← **Load unpacked** ← مجلد `extension`.
3. اختياري: من إعدادات الإضافة فعّل **الخادم السحابي** والصق رابط موقعك على Vercel — يدمج نتائج الخادم مع الفحص المحلي الفوري (الدرجة الأسوأ تحسم، وفشل الخادم لا يعطل الحماية).
> للنشر في متجر Chrome Web Store: اضغط مجلد `extension` في ZIP وارفعه في [لوحة المطورين](https://chrome.google.com/webstore/devconsole) (رسوم تسجيل لمرة واحدة).

## API
| Endpoint | الوظيفة |
|---|---|
| `GET /api/scan?url=...&source=search\|maps\|message\|direct\|shortcut&format=text` | فحص رابط → `{ok, verdict: {score, level, levelText, reasons[], comparison}, display}` — `display` نص عربي جاهز للعرض في التنبيهات، و`format=text` يرجع النص مباشرة بلا JSON (للاختصارات) |
| `POST /api/scan` | نفس الفحص عبر JSON `{url, source}` (يقبل JSON نصياً خاماً أيضاً) |
| `POST /api/report` | بلاغ `{url, note?, level?, source?}` |
| `GET /api/threats` | تجميع الحملات حسب النطاق والمصدر + السجل + البلاغات |
| `GET /api/health` | جاهزية + عدّادات + حالة طبقة AI + النموذج الفعّال |
| `GET /api/shortcut?name=clip\|share` | ملف `.shortcut` جاهز للاستيراد — عنوان الموقع محفور داخله |
- **CORS مفتوح** و`Access-Control-Allow-Origin: *` على كل الـ endpoints (تستخدمها الإضافة واختصارات iOS).
- **حد معدل**: 120 طلب/دقيقة لكل IP لكل نسخة دالة.
- **ملاحظة صريحة**: سجل الفحوصات والبلاغات في ذاكرة كل نسخة دالة (ephemeral) — يُعاد بناؤه بعد إعادة النشر؛ للسجل الدائم اربط قاعدة بيانات لاحقاً.

## الخصوصية والحدود
- الإضافة افتراضياً: **صفر طلبات شبكة** — كل الفحص محلي في الجهاز؛ وضع السحابة اختياري بخدمتك.
- الخادم يفحص الرابط ويحفظ (النطاق + الدرجة + المصدر) في الذاكرة لدعم البلاغات — لا بيانات شخصية ولا محتوى صفحات.
- الفحص القاعدي قواعد محلية (لا WHOIS ولا قوائم حية إلا بربط طبقة AI) — والنتائج مؤشر لا حكم نهائي: لا تزال تعامل الروابط الحساسة بحذر.
- ملفات الاختصارات غير موقعة — استيرادها يتطلب السماح بالاختصارات غير الموثوقة، وحقن العنوان يتم من خادمك أنت فقط.
